# Django

### Crear un entorno virtual en la raíz del proyecto /PavLova-recipes
```
python -m venv venv
```
### Instalar todas las dependencias listadas en requirements.txt en la carpeta /PavLova-recipes/Backend
```
pip install -r requirements.txt
```
### Ejecutar el servidor local en la carpeta /PavLova-recipes/Backend
```
python manage.py runserver
```
