# PavLova Recipes
A social recipe and meal-planning platform that helps home cooks discover and create recipes, while organizing them into nutritionally balanced meal plans manually or with the assistance of AI.

## What We Built

PavLova Recipes combines recipe management with nutritional analysis and
meal planning. Users can create recipes from individual ingredients, calculate
their nutritional information automatically, discover recipes created by
other users, and organize them into personalized meal plans.

The system includes a nutrition calculation engine that handles ingredient
quantities, unit conversions, serving-size adjustments, and nutritional
aggregation. It also includes data-driven components for analyzing and
grouping recipes based on their nutritional characteristics.

## Key Features
- Recipe creation, editing, and deletion
- Ingredient creation, editing, and deletion
- Ingredient-based nutritional calculation
- Automatic adjustment of nutrition based on serving size
- Recipe discovery, ratings, comments, and favorites
- Public and private recipes
- Nutritionally-aware meal planning
- Recipe and meal-plan PDF export
- Data analysis and machine-learning components
- User and recipe moderation.


## Technologies
Frontend: React, Javascript, CSS, HTML
Backend: Python, Django, Pandas.
Database: MySQL.
Other: Docker
